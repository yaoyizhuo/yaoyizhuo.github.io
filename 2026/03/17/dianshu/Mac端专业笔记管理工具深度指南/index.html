3.2 核心操作逻辑与新手快速上手

Keep It 的操作逻辑极为简单，核心只有三步，即使是零经验的新手，也能在 5 分钟内完成文档的管理与编辑，核心操作流程如下：

核心三步操作法

  1. 第一步：添加文档
    有三种方式添加需要管理的文档：

    • 拖拽添加：直接将需要管理的文档，从访达中拖拽到软件的文档列表区，支持批量拖拽多个文件，是最快捷的添加方式；
    • 按钮添加：点击底部状态栏的「+」按钮，在弹出的菜单中选择「新建文档」或「导入文件」，即可添加文档；
    • 右键分享添加：在访达中选中需要管理的文件，右键点击，选择「分享」→「Keep It」，即可快速将文件添加到 Keep It 中。

  2. 第二步：组织文档
    在左侧导航栏中，可通过文件夹、标签、智能文件夹等方式组织文档：

    • 文件夹：点击「文件夹」分类，可创建新文件夹，将文档拖拽到文件夹中进行分类管理；
    • 标签：选中文档，点击右侧信息面板中的「标签」选项，可添加标签，通过标签对文档进行分类；
    • 智能文件夹：点击「智能文件夹」分类，可创建智能文件夹，设置筛选规则，自动整理符合条件的文档。

  3. 第三步：编辑与查看
    选中文档后，在右侧编辑与预览区中，可进行文档的编辑与查看：

    • 文本文档：可直接编辑文本内容，支持富文本格式；
    • Markdown 文档：可使用 Markdown 语法编辑，支持实时预览；
    • PDF 文档：可进行标注、注释等操作；
    • 图片：可查看图片，进行基本的编辑操作。

新手必备小技巧

  1. 批量添加文件时，可直接拖拽整个文件夹，Keep It 会自动将文件夹中的所有文件添加到资料库中；
  2. 选中多个文档后，可统一添加标签、移动到文件夹、导出等操作，无需逐个处理；
  3. 使用搜索功能时，可输入关键词，快速找到需要的文档，支持全文搜索和 OCR 搜索；
  4. 可在偏好设置中，设置文档的默认保存位置、同步选项等，个性化软件的使用体验。

第七章 Keep It 2.7.10 高频问题排查与解决方案

在使用 Keep It 2.7.10 的过程中，可能会遇到一些常见问题，本章节将针对这些问题提供详细的排查与解决方案，帮助用户快速解决问题，确保软件的正常使用。

7.1 同步问题

问题现象

  • 多设备之间文档不同步；
  • 同步过程中出现错误；
  • 同步速度慢。

解决方案

  1. 检查网络连接：确保所有设备都已连接到稳定的网络；
  2. 检查 iCloud 状态：确保 iCloud 存储空间充足，且 iCloud 服务正常；
  3. 重启 Keep It：退出并重新打开 Keep It，触发同步；
  4. 重置同步：在偏好设置中，点击「同步」→「重置同步」，重新开始同步过程；
  5. 检查文件大小：过大的文件可能会导致同步速度慢，可考虑将大文件压缩后再同步。

7.2 性能问题

问题现象

  • 软件运行卡顿；
  • 打开大文件时速度慢；
  • 内存占用过高。

解决方案

  1. 清理缓存：在偏好设置中，点击「高级」→「清理缓存」，清理软件缓存；
  2. 优化存储：定期清理不需要的文档，减少资料库的大小；
  3. 关闭不必要的功能：如实时预览、自动保存等，可在偏好设置中调整；
  4. 更新系统：确保 macOS 系统为最新版本，以获得最佳性能；
  5. 增加内存：如果 Mac 的内存不足，可考虑升级内存。

7.3 文档丢失问题

问题现象

  • 文档突然消失；
  • 文档内容丢失；
  • 无法找到之前的文档。

解决方案

  1. 检查最近删除：点击左侧导航栏的「最近删除」，查看是否有被误删除的文档；
  2. 恢复版本：点击文档的信息面板，查看「版本历史」，恢复之前的版本；
  3. 检查备份：如果启用了自动备份，可从备份中恢复文档；
  4. 搜索文档：使用搜索功能，输入文档名称或关键词，查找文档；
  5. 联系支持：如果以上方法都无法解决，可联系 Keep It 的技术支持。

7.4 导入/导出问题

问题现象

  3. 检查存储空间：确保目标位置有足够的存储空间；
  4. 尝试其他格式：如果导出为某格式失败，可尝试导出为其他格式；
  5. 重启软件：退出并重新打开 Keep It，再次尝试导入/导出操作。

  4. 尝试其他 PDF 阅读器：如果问题持续，可尝试使用其他 PDF 阅读器进行标注；
