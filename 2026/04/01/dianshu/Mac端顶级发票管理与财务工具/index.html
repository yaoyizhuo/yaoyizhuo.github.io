5.1 实战一：自由职业者快速创建第一份专业发票

本实战适合自由职业者、个人从业者，从零开始，快速创建一份专业的服务发票，步骤如下：

  1. 完成企业基础信息配置
    打开 GrandTotal 软件，点击顶部菜单栏「GrandTotal」→「偏好设置」，进入「企业信息」选项卡，填写企业 / 个人的名称、地址、税号、联系方式、银行信息，上传个人 Logo，设置默认的税率、付款期限（比如 15 天），完成基础信息配置，这些信息会自动填充到所有发票中。

  2. 创建客户档案
    在左侧导航栏切换到「客户」模块，点击顶部的「+」号，新建客户档案，填写客户的名称、邮箱、地址、税号等基础信息，设置该客户的默认税率、付款条款，点击保存，完成客户档案的创建。

  3. 新建发票并填写基础信息
    切换到「发票」模块，点击顶部的「新建发票」按钮，在弹出的窗口中，选择刚刚创建的客户，选择默认的发票模板，点击「创建」，软件会自动填充客户信息、企业信息、默认税率、付款期限，生成发票的基础框架，同时自动生成唯一的发票编号。

  4. 添加发票明细项目
    在发票的明细表格中，点击「添加行」，填写服务项目的名称（比如 “网站设计服务”）、描述、数量（1）、单价（5000），选择对应的税率，软件会自动计算金额、税额、总金额。可添加多个明细行，同时可设置折扣、附加费，软件会自动更新总金额。

  5. 填写备注与条款
    在发票的备注区域，填写付款说明、银行信息、服务交付说明，在条款区域，填写付款条款、逾期责任、服务说明等内容，完善发票的完整信息。

  6. 预览与导出发票
    点击顶部的「预览」按钮，查看发票的最终效果，确认内容无误、排版正常后，点击「导出」按钮，选择导出格式为 PDF/A，设置保存路径，点击「导出」，即可完成专业发票的生成。也可点击「发送」按钮，通过邮件直接将发票发送给客户。

  7. 标记付款完成
    收到客户的付款后，在发票列表中选中该发票，点击顶部的「标记付款」，填写付款金额、付款日期、付款方式，点击「确认」，软件会自动将发票标记为已付款状态，同时更新收款统计数据，完成整个开票流程。

  2. 批量生成零散客户发票
    针对月度零散开票的客户，可通过「复制发票」功能，基于上个月的发票快速创建新发票，修改明细项目、金额即可，无需重复录入客户信息、基础条款。也可通过 Excel 导入功能，批量导入发票明细数据，批量生成发票，大幅提升开票效率。

第七章 GrandTotal 9.0.1 高频故障排查与解决方案

很多用户在使用 GrandTotal 9.0.1 的过程中，会遇到软件运行异常、文件损坏、功能操作故障等问题，本章节整理了所有高频出现的故障，并提供详细的解决方案，帮你快速解决问题，恢复正常使用。

7.1 软件运行类故障解决方案

7.1.1 故障 1：软件启动闪退，无法正常打开

解决方案：

  1. 确认你的 Mac 系统版本满足最低要求，macOS 10.13 及以上，老旧系统会出现兼容性问题，无法正常启动；
  2. 确认你使用的是 GrandTotal 9.0.1 稳定版本，测试版可能存在稳定性问题，建议使用官方发布的稳定版；
  3. 重置软件的偏好设置：关闭软件，按住 Option+Command 键，重新打开 GrandTotal，在弹出的窗口中选择「重置偏好设置」，恢复软件的默认设置，解决因配置文件损坏导致的闪退问题；
  4. 关闭冲突的第三方插件：部分老旧插件与新版本 GrandTotal 不兼容，会导致启动闪退，打开访达，进入「~/Library/Application Support/GrandTotal/Plugins」，将插件文件夹重命名，重新打开软件，排查冲突的插件；
  5. 重新部署软件，确保 dmg 文件完整未损坏，避免因文件缺失导致的启动异常。

7.1.2 故障 2：软件运行卡顿、操作延迟，占用过高系统资源

解决方案：

  1. 优化文件数据：如果软件中包含数千条发票记录，会导致运行卡顿，可将已完成的历史发票归档，拆分大型文件，减小当前文件的体积；
  2. 关闭不必要的后台同步：暂停云同步、自动备份功能，避免后台同步占用系统资源，同时关闭实时汇率自动更新等非必要的后台功能；
  3. 升级到 GrandTotal 9.0.1 最新版本，该版本对软件的性能进行了全面优化，大幅降低了 CPU 与内存占用，解决了旧版本的卡顿问题；
  4. 释放系统内存：关闭其他占用内存过高的软件，确保 Mac 有足够的运行内存，处理大型文件时，建议至少预留 8GB 以上的可用内存；
  5. 重启软件，释放内存资源，即可解决临时的卡顿问题。

7.1.3 故障 3：软件频繁崩溃，保存文件时闪退

解决方案：

  1. 检查文件是否过大，发票记录数量过多，导致内存溢出崩溃，可将大型文件拆分为多个子文件，按年度拆分发票数据，减少单个文件的记录数量；
  2. 关闭自动保存与云同步功能，部分情况下自动保存、云同步会触发文件写入冲突，导致崩溃，打开偏好设置，调整自动保存的间隔时间，或关闭云端自动同步；
  3. 排查损坏的发票记录，找到最近编辑的发票记录，删除可能损坏的明细内容，避免因数据损坏导致的崩溃；
  4. 重置软件的渲染设置，打开偏好设置→「高级」，点击「重置渲染设置」，恢复默认的渲染参数，解决渲染导致的崩溃问题；
  5. 检查 Mac 的存储空间，确保系统盘有足够的可用空间，至少预留 10GB 以上的空间，避免因存储空间不足导致的文件保存失败、软件崩溃。

7.2 文件与数据类故障解决方案

7.2.1 故障 1：文件损坏，无法打开，提示文件无效

解决方案：

  1. 恢复文件的自动备份版本：GrandTotal 会自动保存文件的历史备份，打开软件，点击顶部菜单栏「文件」→「打开备份」，选择最近的自动备份文件，打开后重新保存，恢复大部分数据；
  2. 修复损坏的文件：新建一个空白的 GrandTotal 文件，将损坏文件中的页面、数据，逐个复制到新文件中，排查损坏的内容，修复文件；
  3. 使用时间机器恢复：如果你开启了 Mac 的时间机器备份，可通过时间机器，恢复到文件正常的历史版本，找回完整的数据；
  4. 使用官方的文件修复工具，联系官方技术支持，获取文件修复工具，修复损坏的文件。

7.2.2 故障 2：数据丢失，发票记录、客户信息不见了

解决方案：

  1. 检查文件的筛选条件，确认是否开启了筛选器，隐藏了对应的记录，清除所有筛选条件，查看全部记录，确认数据是否真的丢失；
  2. 切换到正确的文件，确认当前打开的是正确的 GrandTotal 文件，避免打开了错误的空白文件；
  3. 恢复自动备份文件，通过「文件」→「打开备份」，找到数据丢失前的备份文件，恢复丢失的记录；
  4. 检查 iCloud / 云同步状态，确认云同步是否完成，数据是否同步完成，等待同步完成后，重新打开文件，查看数据是否恢复；
  5. 检查是否切换了用户档案，确认当前登录的用户是否正确，避免切换了用户，导致数据无法显示。

7.2.3 故障 3：云同步异常，多设备数据不同步

解决方案：

  1. 检查网络连接，确保 Mac 可正常访问 iCloud/Dropbox 等云存储服务，网络不稳定会导致同步失败；
  2. 检查云存储空间，确认云存储有足够的可用空间，空间不足会导致同步失败；
  3. 重启软件的同步功能，关闭同步功能，重新开启，强制触发一次全量同步，解决同步卡住的问题；
  4. 检查多设备的软件版本，确保所有设备的 GrandTotal 版本一致，旧版本与新版本的文件格式可能存在差异，导致同步异常；
  5. 手动同步文件，将最新的文件手动保存到云存储中，在其他设备上手动打开，完成数据同步。

7.3 功能操作类故障解决方案

7.3.1 故障 1：模板编辑异常，元素无法编辑、排版错乱

解决方案：

  1. 检查元素是否被锁定，选中无法编辑的元素，右键查看是否开启了锁定，解锁后即可正常编辑；
  2. 重置模板编辑器，关闭模板编辑窗口，重新打开，解决临时的渲染异常问题；
  3. 检查模板中的条件显示规则，确认是否设置了错误的条件，导致元素隐藏、排版错乱，修改错误的条件规则即可恢复；
  4. 恢复模板的默认版本，如果你是基于内置模板修改的，可重新导入内置模板，基于默认模板重新修改，避免模板文件损坏导致的异常；
  5. 重启软件，重置渲染引擎，解决元素无法渲染、编辑异常的问题。

7.3.2 故障 2：税务计算错误，金额、税额计算异常

解决方案：

  1. 检查税率设置是否正确，确认明细行的税率选择无误，税率值设置正确，没有出现小数点错误；
  2. 检查折扣、附加费的设置，确认折扣的计算方式正确，没有出现重复计算、计算顺序错误的问题；
  3. 重置税务计算规则，打开偏好设置→「税务」，点击「重置税务设置」，恢复默认的计算规则，解决因设置错误导致的计算异常；
  4. 检查币种与汇率设置，确认汇率设置正确，没有出现汇率错误导致的金额计算异常；
  5. 重新创建发票，复制明细内容到新的发票中，重新计算，解决因单条发票数据损坏导致的计算错误。

7.3.3 故障 3：PDF 导出失败，导出的文件排版错乱、内容缺失

解决方案：

  1. 检查模板的页面设置，确认页面尺寸、边距设置正确，没有出现内容超出页面范围的问题，调整页面边距，确保所有内容都在页面范围内；
  2. 检查模板中的元素，确认没有使用损坏的图片、字体，替换异常的图片与字体，避免因资源损坏导致的导出失败；
  3. 更换导出格式，尝试导出为标准 PDF 格式，而非 PDF/A 格式，解决因归档格式导致的导出异常；
  4. 关闭后台的其他 PDF 处理软件，避免软件冲突导致的导出失败，同时确保系统有足够的存储空间，保存导出的文件；
  5. 重启软件，重新导出，解决临时的渲染异常导致的导出文件排版错乱问题。

7.4 集成与协同类故障解决方案

7.4.1 故障 1：邮件发送失败，无法通过软件发送发票邮件

解决方案：

  1. 检查系统邮件应用的设置，确认系统邮件 APP 已正确配置邮箱账号，可正常发送邮件，GrandTotal 是调用系统邮件应用发送邮件，系统邮件异常会导致发送失败；
  2. 检查收件人邮箱地址是否正确，确认客户的邮箱地址填写无误，没有出现格式错误、地址错误；
  3. 检查邮件附件大小，确认发票文件大小没有超过邮箱的附件限制，过大的文件会导致发送失败；
  4. 更换邮件发送方式，将发票导出为 PDF 文件，手动通过邮箱客户端发送，避免软件调用异常；
  5. 检查网络连接，确保网络稳定，可正常访问邮箱服务器，网络不稳定会导致邮件发送失败。

7.4.2 故障 2：第三方软件集成异常，无法导入工时、项目数据

解决方案：

  1. 确认第三方软件的版本与 GrandTotal 9.0.1 兼容，旧版本的第三方软件可能与新版本不兼容，升级第三方软件到最新版本；
  2. 检查集成权限设置，确认 GrandTotal 有权限访问第三方软件的数据，在 macOS 系统设置→隐私与安全性中，开启对应的权限；
  3. 重新配置集成连接，断开第三方软件的对接，重新完成授权配置，解决连接异常导致的导入失败；
  4. 检查第三方软件的数据格式，确认导出的数据格式符合 GrandTotal 的导入要求，避免因格式错误导致的导入失败；
  5. 安装对应的集成插件，部分第三方软件需要安装对应的插件才能实现对接，安装最新版本的插件，即可解决集成异常问题。
