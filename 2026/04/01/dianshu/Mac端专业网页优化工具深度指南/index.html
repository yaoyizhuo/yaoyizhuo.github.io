第四章 Scrutiny 12.10.2 核心功能全解析

Scrutiny 12.10.2 构建了一套覆盖网页优化全场景的功能体系，从基础的死链接检测，到进阶的 SEO 分析、站点地图生成、性能分析，功能全面且专业。本章节将对核心功能进行深度拆解，帮你彻底掌握 Scrutiny 的全部能力。

4.1 网站链接检查

网站链接检查是 Scrutiny 的核心功能之一，用于检测网站中的死链接、重定向链接、不安全链接等问题。

4.1.1 死链接检测

Scrutiny 会扫描网站中的所有链接，包括内部链接和外部链接，检测是否存在死链接（404 错误）。死链接会影响用户体验和搜索引擎排名，及时发现和修复死链接对网站优化至关重要。

4.1.2 重定向链接检测

Scrutiny 会检测网站中的重定向链接，包括 301 永久重定向和 302 临时重定向，确保重定向链接的正确性和合理性。

4.1.3 不安全链接检测

Scrutiny 会检测网站中的不安全链接（HTTP 链接），特别是在 HTTPS 网站中，不安全链接会影响网站的安全性和用户体验。

4.1.4 链接深度分析

Scrutiny 会分析网站的链接深度，确保重要页面的链接深度合理，便于搜索引擎抓取和用户访问。

4.2 SEO 分析

SEO 分析是 Scrutiny 的重要功能之一，用于评估网站的 SEO 表现，提供优化建议。

4.2.1 页面标题分析

Scrutiny 会分析网站页面的标题（Title），检查标题的长度、关键词使用、唯一性等，确保标题符合 SEO 最佳实践。

4.2.2 元描述分析

Scrutiny 会分析网站页面的元描述（Meta Description），检查元描述的长度、关键词使用、吸引力等，确保元描述能够吸引用户点击。

4.2.3 关键词分析

Scrutiny 会分析网站页面的关键词使用情况，包括关键词密度、关键词分布、长尾关键词等，提供关键词优化建议。

4.2.4 标题标签分析

Scrutiny 会分析网站页面的 H1-H6 标题标签，检查标题标签的使用情况、层次结构、关键词使用等，确保标题标签符合 SEO 最佳实践。

4.2.5 核心 web 指标分析

Scrutiny 12.10.2 新增了对核心 web 指标（Core Web Vitals）的分析，包括 Largest Contentful Paint (LCP)、First Input Delay (FID)、Cumulative Layout Shift (CLS) 等，帮助用户优化网站的用户体验和搜索排名。

4.3 站点地图生成

站点地图生成是 Scrutiny 的核心功能之一，用于生成 XML、HTML、CSV、DOT 等格式的站点地图，帮助搜索引擎更好地索引网站内容。

4.3.1 XML 站点地图

Scrutiny 可以生成符合 Google 标准的 XML 站点地图，包含网站的所有页面、图片、视频等内容，提交给搜索引擎后可以提高网站的索引效率。

4.3.2 HTML 站点地图

Scrutiny 可以生成 HTML 格式的站点地图，方便用户浏览和导航网站内容，提高用户体验。

4.3.3 CSV 站点地图

Scrutiny 可以生成 CSV 格式的站点地图，方便用户在电子表格软件中分析和处理网站结构。

4.3.4 DOT 站点地图

Scrutiny 可以生成 DOT 格式的站点地图，以图形化的方式展示网站的结构和链接关系，便于用户理解网站的整体结构。

4.4 HTML 验证

HTML 验证是 Scrutiny 的重要功能之一，用于检查网站的 HTML 代码是否符合标准，确保网站的兼容性和可访问性。

4.4.1 HTML 语法检查

第七章 Scrutiny 12.10.2 常见问题与解决方案

在使用 Scrutiny 12.10.2 的过程中，可能会遇到一些常见问题，本章节将汇总这些问题，并提供对应的解决方案，帮助你快速排查并解决问题。

7.1 扫描问题

7.1.1 扫描速度慢

问题表现：扫描大型网站时，扫描速度非常慢，需要很长时间才能完成。

解决方案：

  1. 调整扫描设置，减少扫描深度，排除不需要扫描的页面或目录。
  2. 增加线程数，提高扫描速度，但注意不要设置过高，以免对服务器造成负担。
  3. 分批扫描，将大型网站分为多个部分，分别扫描，然后合并结果。

7.1.2 扫描中断

问题表现：扫描过程中，扫描中断，无法完成扫描。

解决方案：

  1. 检查网络连接，确保网络连接稳定。
  2. 调整超时时间，增加超时时间，避免因网络延迟导致扫描中断。
  3. 减少扫描深度和线程数，减轻服务器负担，避免服务器拒绝连接。

7.2 分析问题

7.2.1 分析结果不准确

问题表现：分析结果与实际情况不符，如死链接检测错误、SEO 分析不准确等。

解决方案：

  1. 检查扫描设置，确保扫描设置合理，如扫描深度足够、排除规则正确等。
  2. 手动验证分析结果，如手动访问死链接、检查页面的 SEO 元素等。
  3. 更新 Scrutiny 到最新版本，修复已知的分析问题。

7.2.2 分析结果不完整

问题表现：分析结果不完整，如某些页面没有被扫描、某些分析项缺失等。

解决方案：

  1. 检查扫描设置，确保扫描深度足够，能够扫描到所有需要的页面。
  2. 检查排除规则，确保没有排除需要扫描的页面或目录。
  3. 增加线程数和超时时间，提高扫描的完整性。

7.3 报告问题

7.3.1 报告生成失败

问题表现：无法生成报告，或生成的报告不完整。

解决方案：

  1. 检查磁盘空间，确保有足够的磁盘空间生成报告。
  2. 检查报告设置，确保报告设置合理，如报告格式正确、报告内容选择适当等。
  3. 减少报告内容，只包含需要的信息，避免报告过大导致生成失败。

7.3.2 报告格式错误

问题表现：生成的报告格式错误，如 PDF 报告无法打开、HTML 报告显示异常等。

解决方案：

  1. 检查报告设置，确保报告格式设置正确。
  2. 尝试使用其他报告格式，如从 PDF 格式改为 HTML 格式。
  3. 更新 Scrutiny 到最新版本，修复已知的报告格式问题。

7.4 性能问题

7.4.1 软件运行缓慢

问题表现：Scrutiny 运行缓慢，操作响应不及时。

解决方案：

  1. 检查系统资源，确保有足够的内存和 CPU 资源。
  2. 关闭不必要的应用程序，释放系统资源。
  3. 减少扫描深度和线程数，减轻软件的负担。
  4. 更新 Scrutiny 到最新版本，优化软件性能。

7.4.2 内存占用过高

问题表现：Scrutiny 内存占用过高，导致系统卡顿。

解决方案：

  1. 减少扫描深度，避免扫描过多的页面。
  2. 减少线程数，减轻软件的负担。
  3. 分批扫描，将大型网站分为多个部分，分别扫描。
  4. 关闭不必要的分析项，只启用需要的分析功能。

7.5 兼容性问题

7.5.1 macOS 系统更新后无法运行

问题表现：macOS 系统更新后，Scrutiny 无法正常运行，或出现闪退。
