第五章 Irvue 2026.2 全场景实战操作教程

5.1 实战一：浏览与收藏高质量壁纸

这是最常用的壁纸获取场景，通过 Irvue 可浏览和收藏高质量的壁纸，步骤如下：

  1. 打开 Irvue
    在应用程序文件夹中找到 Irvue 并打开，或通过 Spotlight 搜索打开。

  2. 浏览壁纸
    主界面会显示推荐的壁纸，可左右滑动浏览更多，也可使用筛选功能缩小范围。

  3. 筛选壁纸
    使用顶部的筛选工具，按分辨率（如 4K）、方向（如横版）、颜色（如蓝色）等条件筛选。

  4. 预览壁纸
    点击感兴趣的壁纸，查看大图预览效果。

  5. 收藏壁纸
    喜欢的话，点击右下角的「收藏」按钮，或按键盘上的「F」键收藏。

  6. 创建收藏夹
    首次收藏时，会提示创建新收藏夹，输入名称后点击「创建」即可。

5.2 实战二：设置自动更换壁纸

针对希望壁纸自动更换的场景，Irvue 可实现完全自动化的壁纸更换，步骤如下：

  1. 打开设置
    点击菜单栏的 Irvue 图标，选择「自动更换设置」。

  2. 启用自动更换
    在设置窗口中，勾选「启用自动更换」。

  3. 设置更换频率
    选择更换频率，如「每小时」「每天」等，也可自定义具体时间。

  4. 设置更换来源
    选择自动更换时使用的壁纸来源，可选择多个来源。

  5. 设置排除规则
    点击「排除选项」，设置不参与自动更换的收藏夹或标签。

  6. 保存设置
    点击「保存」按钮，保存设置，自动更换开始生效。

5.3 实战三：管理收藏夹

针对收藏较多需要整理的场景，Irvue 提供了完善的收藏夹管理功能，步骤如下：

  1. 打开收藏夹
    在主界面侧边栏中，点击「收藏夹」选项。

  2. 创建新收藏夹
    点击「+」按钮，创建新的收藏夹，输入名称并选择图标。

  3. 移动壁纸
    选中壁纸，点击「移动到」，选择目标收藏夹，即可移动。

  4. 批量操作
    按住 Command 键选中多个壁纸，可进行批量移动、删除等操作。

  5. 重命名收藏夹
    右键点击收藏夹，选择「重命名」，输入新名称即可。

  6. 导出收藏夹
    右键点击收藏夹，选择「导出」，选择保存位置和格式即可。

针对不同屏幕和壁纸尺寸的需求，Irvue 支持多种显示模式，步骤如下：

  1. 选择壁纸
    在收藏夹或壁纸列表中选择一张壁纸。

  2. 右键设置
    右键点击壁纸，选择「设置为桌面壁纸」。

  3. 选择显示模式
    在子菜单中，选择显示模式，如「适应」「填充」「居中」等。

  4. 预览效果
    可先点击「预览」查看效果，再确认设置。

  5. 应用到所有显示器
    如有多个显示器，可选择「应用到所有显示器」。

5.5 实战五：使用快捷键提高效率

Irvue 支持丰富的快捷键，可大幅提升操作效率，步骤如下：

  1. 查看快捷键
    打开 Irvue，按住 Command 键点击菜单栏的「Irvue」菜单，选择「快捷键」。

  2. 常用快捷键

    在偏好设置中，点击「快捷键」标签，自定义快捷键。

  4. 使用快捷键
    熟练使用快捷键后，可大幅提升壁纸管理效率。

针对使用多显示器的用户，Irvue 提供了完善的多显示器支持，步骤如下：

  2. 设置主显示器
    选择主显示器，设置壁纸和显示模式。

    选择副显示器，设置独立的壁纸。

    如需所有显示器同步更换，勾选「同步更换」选项。

  5. 跨屏壁纸
    如有全景壁纸，可选择「跨屏显示」，在整个桌面上显示。
